### <a name="_3bfxc9a45514"></a>**Функциональные требования**

| №   | Действующие лица или системы                                                     | Use Case                                                           | Описание                                                                                                                                                   |
|-----|----------------------------------------------------------------------------------|--------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 1   | Клиент, оператор КЦ, система КЦ банка, сервис депозитов                          | Консультация по текущим ставкам с колл-центром банка               | Клиент и оператор КЦ консультируются по вопросам депозита. ### <a name="_u8xz25hbrgql"></a>**Нефункциональные требования**

| №   | Требование                                                                                                 |
|-----|------------------------------------------------------------------------------------------------------------|
| 1   | Данные при передаче необходимо защищать с помощью механизма шифрования трафика                             |
| 2   | У партнерского КЦ нет возможности сделать API-вызовы (они готовы получать актуальные ставки в виде файлов) |
| 3   | Отклик в 99.9% случаев                                  |
| 4   | Использовать протокол SFTP для обмена данными с партнерским кол-центром                                                      |

### <a name="_qmphm5d6rvi3"></a>**Решение**
Диаграмы в файлах container и сontext. 

Добавлен микросервис депозитов (потенциально и кредитов) для взаимодействия АБС, что позволит не использовать апи АБС напрямую.
Микросервис и его БД реализованы на тех же технологиях, что и интернет-банк, чтобы была экспертиза у команды.
Этот же микросервис отправляет через протокол SFTP файл со ставками в партнерский КЦ

### <a name="_bjrr7veeh80c"></a>**Альтернативы**
- Использование других протоколов доставки ставок - увеличивает риски, т к неизвестно о стоимости доработок на стороне подрядчика

**Недостатки, ограничения, риски**

Низкая скорость обновления данных по ставкам, риски недоставки данных по ставкам => отсутствие актуальной информации у операторов партнерского КЦ
